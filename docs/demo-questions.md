# PSC Demo Questions

ชุดนี้ออกแบบมาเพื่อ demo แบบลดความเสี่ยงการเดา โดยเลือกคำถามที่มีข้อมูลในเว็บไซต์ PSC และคู่มือนักศึกษา 2568 ที่ ingest เข้า Supabase แล้ว

## Recommended Flow

1. สมัครเรียน ปวช. ต้องใช้เอกสารอะไรบ้าง
   - ใช้โชว์ว่า bot ตอบจากหน้าสมัครเรียนได้
   - ความมั่นใจ: สูง

2. สมัครเรียน ปวส. ต้องใช้เอกสารอะไรบ้าง
   - ใช้โชว์ว่าระบบแยกข้อมูล ปวช./ปวส. ได้
   - ความมั่นใจ: สูง

3. วิทยาลัยเปิดสอนหลักสูตรอะไรบ้าง
   - ใช้โชว์ภาพรวมหลักสูตร ปวช. และ ปวส.
   - ความมั่นใจ: สูง

4. สาขาการตลาดดิจิทัลเรียนเกี่ยวกับอะไร
   - ใช้โชว์คำถามเฉพาะสาขา
   - ความมั่นใจ: กลางถึงสูง

5. ชำระค่าเทอมได้ช่องทางไหน
   - ใช้โชว์ข้อมูลฝ่ายการเงินและช่องทางชำระเงิน
   - ความมั่นใจ: สูง

6. กยศ. รายใหม่ต้องเตรียมตัวอย่างไร
   - ใช้โชว์ข้อมูลประกาศ/ข่าวล่าสุดจากเว็บไซต์
   - ความมั่นใจ: กลางถึงสูง

7. ระเบียบการแต่งกายของนักศึกษามีอะไรบ้าง
   - ใช้โชว์ว่าดึงข้อมูลจาก PDF คู่มือนักศึกษาได้
   - ความมั่นใจ: สูง

8. ถ้ามาสายหรือขาดเรียนมีระเบียบอย่างไร
   - ใช้โชว์ข้อมูลระเบียบวินัยจาก PDF
   - ความมั่นใจ: สูง

9. คู่มือนักศึกษา 2568 มีข้อมูลเรื่องอะไรบ้าง
   - ใช้โชว์ว่า PDF ทั้งเล่มถูก ingest เป็น knowledge base
   - ความมั่นใจ: กลาง

10. มีหอพักนักศึกษาไหม
    - ใช้โชว์ guardrail ว่าถ้าไม่มีข้อมูล ระบบควรตอบว่าไม่พบข้อมูลในเอกสาร
    - ความมั่นใจ: สูงสำหรับการทดสอบว่าไม่เดา

## Avoid For Now

- ค่าเทอมทั้งหมดเท่าไหร่
- ตารางเรียนแต่ละห้องเป็นอย่างไร
- รายละเอียดล่าสุดจาก Facebook ทั้งหมด
- เบอร์โทรเฉพาะฝ่ายที่ไม่ได้อยู่ในเอกสาร

คำถามกลุ่มนี้เสี่ยง เพราะข้อมูลอาจไม่ครบในชุดเอกสารที่ ingest ตอนนี้ ควรเพิ่มแหล่งข้อมูลก่อนใช้บนเวที
